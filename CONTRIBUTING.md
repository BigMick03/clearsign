# Contributing

- Setup: `pnpm install`
- Tests: `pnpm test`
- Commits: Follow conventional commits format (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).
- PRs: Ensure all tests pass, linter is clean, and docs are updated.

## Stellar Wave
This project is part of the Stellar Wave program. Issues labeled with "wave" are eligible for program rewards. Request assignment on issues before starting work.
